# WordPress.org listing assets

Files here are copied to the plugin's SVN `assets/` folder (beside `trunk/` and `tags/`)
by the `Build Release` workflow, in the same commit as each release. This README is not
copied. Nothing in this folder ships in the plugin zip.

- `icon-128x128.png`, `icon-256x256.png` (or a single `icon.svg`)
- `banner-772x250.png`, `banner-1544x500.png` (retina)
- `screenshot-1.png`, `screenshot-2.png`, ... with captions under `== Screenshots ==` in
  `stop-user-enumeration/readme.txt`
- `blueprints/blueprint.json` (optional WordPress Playground preview)

PNG or JPG. Changes reach the listing with the next release.

See https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/
